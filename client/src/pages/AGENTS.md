# Client Pages

## OVERVIEW
React 19 route pages with shadcn/ui + Tailwind CSS v4.

## PAGES
| File | Purpose |
|------|---------|
| `CreatePoll.tsx` | Poll creation form |
| `Home.tsx` | Poll listing |
| `LivePoll.tsx` | Real-time voting display |
| `PollDetail.tsx` | Poll management |
| `Results.tsx` | Vote results |
| `Login.tsx` | Auth/login |

## STATE
React Query for server state. WebSocket via `useWebSocket` hook.
